# FRIDAY Ultra — Web Dashboard Guide

Aapne successfully FRIDAY ke liye ek naya, futuristic **Web Dashboard** install kar liya hai.

## Launch Kaise Karein?

Dashboard ko chalane ke liye bas ye command run karein:

```bash
python run_web.py
```

Isse do cheezein start hongi:
1.  **Backend Bridge:** `http://localhost:8000` (FastAPI)
2.  **Frontend Dashboard:** `http://localhost:5173` (React)

## Features
- **Futuristic UI:** Animated "Jarvis" style interface.
- **Real-time Interaction:** Python backend se seedha connected.
- **Voice Visualization:** Jab FRIDAY bolegi, dashboard par waves dikhengi.

## Safety Note
Aapka purana system (`main.py`) bilkul pehle jaisa hi kaam karega. Ye Dashboard uske upar ek naya "layer" hai.
